# SubiCode security

Report security issues privately through [LearnSmart support](https://stlearnsmart.in/contact). Include the affected version, operating system, reproduction steps and impact. Do not post credentials or private project data in public issues.

SubiCode can read and edit files, run shell commands and invoke connected tools. Permission prompts help control actions; they are not an operating-system sandbox. Use an isolated workspace or VM for untrusted projects. Review MCP servers, plugins and skills before enabling them.

Provider data handling follows the provider you select. Keep credentials out of source control and logs. Device pairing grants access to the host service; enable remote access only when intended, protect pairing links and revoke devices you no longer use.
